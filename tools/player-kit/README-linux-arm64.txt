This is the download for 64-bit ARM computers (glibc 2.35 or later, a
Vulkan 1.3 driver, 4 GB of memory or more). On a Raspberry Pi 4 or 5 the
game builds (slowly: leave the first build running, it can take an hour or
more), but it isn't expected to run at full speed there yet: making that
possible is still to come. The Pi's Vulkan 1.3 driver came with Mesa 24.3
(Raspberry Pi OS Trixie or later).
